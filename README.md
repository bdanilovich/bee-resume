# Bryan's Bee Resume

A joke résumé applying for "literally any position" at Barnes Backyard Bees. Bee whisperer (whispering because I'm hiding), sales closer, professional jar opener.

**[View it live →](https://bdanilovich.github.io/bee-resume/)**

## How it was made

A small weekend project, just for fun. I ran into a friend who runs a sideline beekeeping and honey business with his two young sons, and I joked with the boys that they needed to hire me. I promised a résumé, so I had Claude Code make one. I gave it minimal instruction, and it understood the assignment. It's a single HTML file. Click the bee.

I [posted it on LinkedIn](https://www.linkedin.com/feed/update/urn:li:activity:7517984894464200704/). I didn't get the job.
